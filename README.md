# Teacher's Day Folder Greeting Card

A personalized, responsive Teacher's Day greeting card for Sir Randy, made by Jimuel Porcare. The folder cover opens with a 3D page-like animation to reveal the message and teacher photo.

## Project files

- `index.html` — card content and structure
- `style.css` — colors, layout, responsive styling, and opening animation
- `script.js` — open/close interaction
- `assets/teacher-photo.jpg` — teacher photo used in the card

## How to view

1. Keep the `index.html`, `style.css`, `script.js`, and `assets` folder together.
2. Double-click `index.html` or open it in a browser.
3. Click the folder cover to reveal the greeting. Click **Close the card** to close it again.

An internet connection is needed to load the Google Fonts. The page itself works locally without a server.

## Customize

- Edit the greeting and teacher's name in `index.html`.
- Replace `assets/teacher-photo.jpg` with another image, keeping the same filename.
- Change the palette and visual style in `style.css`.
- Adjust the open/close behavior in `script.js`.

## Upload to GitHub

1. Create a new **public** repository on GitHub.
2. Upload the project files and the `assets` folder (or upload the ZIP contents after extracting).
3. Commit the files.
4. Copy the repository URL and submit that link.

To publish it as a live webpage, enable **Settings → Pages**, choose the `main` branch and `/ (root)` folder, then save. GitHub will provide a Pages URL after publishing.
