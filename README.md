Teacher's Day Greeting Card
🍃 For Sir Randy ---
A personalized, interactive Teacher's Day greeting card made with
HTML, CSS, and JavaScript. The design uses a forest-green folder
that opens with a 3D animation to reveal a thank-you message.
✨ Features
📂 Click-to-open folder cover with a 3D page-opening effect
💌 Personalized Teacher's Day message for Sir Randy
🖼️ Teacher portrait area
📱 Responsive layout for desktop and mobile screens
♿ Accessible button labels and keyboard focus styling
🌿 Calm forest-green, cream, and gold color palette
🎞️ Respects the device's reduced-motion preference
📁 Project Structure
``` text
Teachers-Day-Message-Card/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── teacher-photo.jpg
```
> Make sure the `assets` folder and `teacher-photo.jpg` image exist. The
> HTML currently refers to `assets/teacher-photo.jpg`.
🚀 How to Run
Download or clone the project.
Keep `index.html`, `style.css`, and `script.js` in the same folder.
Create an `assets` folder beside `index.html` if it does not exist.
Add the teacher's photo as `teacher-photo.jpg` inside `assets`.
Open `index.html` in a web browser.
No installation or build process is required.

🖱️ How to Use
Click "CLICK TO OPEN" on the folder cover to reveal the
greeting.
Click "↺ Close the card" to close it again.
🛠️ How to Customize
Change the message
Open `index.html` and edit the text inside the `.message` section. You
can change the teacher's name, greeting, message, closing, and
signature.
Change the teacher's photo
Replace `assets/teacher-photo.jpg` with your chosen image, keeping the
same filename. Alternatively, update the image path in `index.html`.
Change the design
Edit `style.css`. The main colors are defined near the top in `:root`:
`--forest` --- forest green
`--forest-dark` --- darker green
`--sage` --- sage green
`--cream` --- cream
`--paper` --- paper white
`--gold` --- gold
`--ink` --- text color
You can also adjust typography, spacing, layout, and animations in this
file.
Change the interaction
Edit `script.js` to customize what happens when the folder opens or
closes.
🧰 Technologies
HTML5
CSS3 (transforms, transitions, responsive media queries)
Vanilla JavaScript
Google Fonts: DM Sans and Playfair Display
📝 Notes
An internet connection is needed to load the Google Fonts; the card
itself works locally with fallback fonts.
The current project includes a photo area but does not implement
audio playback.
This project was created as a personalized appreciation message for
World Teachers' Day.
